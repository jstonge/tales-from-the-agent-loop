# liquid-lfm3

> [!agent] Claude summary
> Liquid AI's LFM3 is a family of ~2B parameter multimodal models using a tri-hybrid architecture of gated convolutions, sliding-window attention, and global attention to optimize for on-device agentic use cases. The text model is specifically post-trained for agentic harnesses like [[pi]], showing strong performance in tool use and long-context tasks compared to larger models. The release includes specialized vision, audio, omni, and "decision" models, the latter of which provide calibrated probabilities for structured tasks in a single forward pass.
