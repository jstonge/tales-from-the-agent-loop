# anomalyco-opencode-repo

Claude summary:

> OpenCode calls itself "the open source AI coding agent", but almost all of the README is install instructions: about a dozen package-manager lines, a desktop app in beta, and the rules for choosing an install path. The only design it describes is a mode split. There's a full-access `build` agent, a `plan` agent that refuses file edits and asks before running shell commands, toggled with Tab, plus a `general` subagent you call with `@general`. That's the same read-only-planning versus acting split Claude Code has, done as two named agents instead of a permission mode. Nothing here covers the loop, context handling, which models it supports, or how it's extended, all of which live in the docs. That makes this archive the storefront, much like [[deepseek-harness-repo]], and a poor basis for comparing it with [[pi-how-pi-works]].
