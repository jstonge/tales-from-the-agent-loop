# Alishahryar1

## Who

> [!claude] Claude summary
> Ali Khokhar, author of Free Claude Code — a proxy that sits where Anthropic's
> API would be and routes an agent's calls to NVIDIA NIM, OpenRouter, DeepSeek, or
> a local LM Studio or llama.cpp. MIT-licensed, Python and FastAPI, and widely
> picked up: around 37k GitHub stars as reported. It works with Codex, Pi,
> OpenCode, Cline, DeepSeek Harness and Aider as well as Claude Code.
>
> That breadth is the reason it's here — swapping the model under a fixed harness
> is the cleanest way to test how much of an agent's behaviour is the harness
> rather than the model.
