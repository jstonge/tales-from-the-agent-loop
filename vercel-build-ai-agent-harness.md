# vercel-build-ai-agent-harness

Although it was most certainly at least partly written by an agent, it remains a good introduction to building a custom agent coding loop. It works through a concrete example of building an agent from scratch, with exercises to show what happens when you forgo this or that tool. I hope to find a better reference for building agents from scratch (see [[wickham-what-is-an-agent]] for better one), but this one is alright to get started, I guess
